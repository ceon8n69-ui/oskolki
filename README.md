# Осколки королевств

Telegram Mini App — стратегия на большой карте с **одновременным планированием ходов**: все игроки отдают приказы, затем сервер рассчитывает результат. Бот: [@oskolki_k_bot](https://t.me/oskolki_k_bot).

## Статус — этапы 1–5, серверная часть (v0.6)

Готово и покрыто тестами:

- **Правила** (`src/engine`) — чистый детерминированный модуль без клиента и сервера: пути по стоимости местности, одновременное движение с разрешением конфликтов, бой по ступеням инициативы, контратаки, укрепление, захват городов в два расчёта, экономика с резервом и одноразовым списанием, исследования, найм, туман войны и устаревшие разведданные, ранги. Порядок расчёта — [docs/TURN_RESOLUTION.md](docs/TURN_RESOLUTION.md).
- **Генератор мира** (`src/worldgen`) — по seed, чанки 16×16, автоматическая проверка (доступность столиц, расстояния по реальной стоимости движения, поселение и объект рядом со стартом, честность старта, замкнутые области), отчёт и ASCII-просмотр.
- **Сервер** (`src/server`) — Fastify + PostgreSQL + WebSocket: авторизация по Telegram initData, лобби и приглашения, приказы с версиями и ключами идемпотентности, готовность, расчёт хода в одной транзакции под блокировкой партии, журнал событий с фильтром видимости, снимки для воспроизведения, планировщик сроков.
- **Бот** (`src/bot`) — `/start` с кнопкой игры, приглашения `startapp=join_…`, уведомления (объединяются в одно сообщение за ход), `/settings`, `/help`; polling или webhook.
- **Клиентский SDK** (`src/client-sdk`) — сеть, переподключение, кеш чанков, приказы с повторами, шкала воспроизведения хода (×1/×2, пропуск, уменьшенное движение).
- **Бот-противник** (`src/ai`) — видит только то же, что игрок.
- **Отладочный клиент** (`web/`) — вид сверху без графики, чтобы проверять партию целиком.

**Этап 2 (большой мир):** кампания 256×256 до 32 игроков, генерация в отдельном потоке с выравниванием стартов, долгие маршруты на несколько ходов (с остановкой при угрозе), строительство дорог, мини-карта, сжатые снимки и кеш состояния. Замеры — [docs/LOAD_TEST.md](docs/LOAD_TEST.md).

**Этап 3 (стратегическая глубина):** четыре народа с собственными механиками, командирами, двумя уникальными отрядами и ветками наследия; восемь базовых классов; 25 общих и по 4 уникальных технологии, в том числе взаимоисключающие; постройки, рост и специализации городов; материалы (древесина, железо, кристаллы); снабжение и лечение; прокачка с выбором улучшения; тактика — зона контроля, прикрытие, строй, высота, подавление, отталкивание, засады, укрепления. Справочник — [docs/RULES.md](docs/RULES.md) (генерируется из конфигурации: `npm run docs`).

**Этап 4 (кампания):** дипломатия (война, перемирие с закрытой территорией, союз с общим обзором и метками, разрыв с периодом предупреждения), условия победы на выбор при создании партии (очки влияния за объявленные цели с лимитом ходов, захват столиц, до последнего), боты в лобби, замещение отсутствующих игроков ботом с возвратом управления, полный журнал приказов (в том числе ботов) для воспроизведения.

**Этап 5 (расширение, техническая часть):** шесть народов — добавлены Пепельные орды (натиск, выжженная земля, добыча; цена широкого фронта) и Хранители руин (сеть обелисков с полем резонанса; зависимость от узлов); полные ветки исследований — 30 общих и по 6 уникальных на народ; флот (транспорт и боевой корабль), порты, погрузка и высадка; награды руин; мировые события; карты «Архипелаг 64×64» и «Материк 128×128»; бот умеет разведку, переправу, обелиски и выжигание; балансные прогоны «бот против бота» (`npm run simulate`, отчёт — [docs/BALANCE.md](docs/BALANCE.md)). Анимации, звуки и финальные модели — за графикой.

Графика (low-poly изометрия, модели, анимации) — отдельная задача: контракт в [docs/RENDERER_CONTRACT.md](docs/RENDERER_CONTRACT.md). Старый одиночный прототип 0.1 лежит в `legacy/` для справки.

## Запуск локально

Node.js ≥ 22.18 (TypeScript запускается напрямую, без сборки), PostgreSQL 14+.

```sh
npm install
createdb oskolki
DEV_AUTH=1 npm run build && DEV_AUTH=1 npm start   # http://localhost:3000, вход по имени
```

Проверки:

```sh
npm run check            # типы, границы модулей, все тесты (нужна БД oskolki_test)
npm run worldgen -- --preset test32 --seed demo --ascii
npm run bench -- --preset world256 --units 2000      # нагрузка расчёта хода
npm run load-test -- --turns 5 --units 2000          # полный цикл с PostgreSQL
```

`DATABASE_URL_TEST` задаёт тестовую БД (по умолчанию `postgres://oskolki:oskolki@localhost:5432/oskolki_test`; тесты пересоздают её схему).

## Развёртывание на Railway

1. Сервис из этого репозитория + плагин PostgreSQL (переменная `DATABASE_URL` подставится).
2. Переменные — по образцу `.env.example`: `PUBLIC_URL`, `BOT_TOKEN`, `BOT_MODE=webhook`, `WEBHOOK_SECRET`, `SESSION_SECRET`, `ADMIN_TOKEN`.
3. Сборка и запуск заданы в `railway.json`; миграции применяются при старте; проверка — `GET /health`.
4. Бот при старте сам ставит webhook, команды и кнопку меню «Играть» на `PUBLIC_URL`.

Несколько инстансов безопасны: ход партии считает только тот, кто взял строку партии (`FOR UPDATE SKIP LOCKED`). Redis на этапе 1 не нужен — координацию делает PostgreSQL; он понадобится при выносе расчёта в отдельных воркеров.

## Структура

```
config/balance.v1.json   баланс (юниты, местность, технологии, экономика, пресеты карт и ходов)
src/shared               типы состояния и протокола
src/engine               правила (без ввода-вывода)
src/worldgen             генерация и проверка мира
src/ai                   бот-противник
src/server               API, БД, планировщик
src/bot                  Telegram-бот
src/client-sdk           клиентская библиотека для любого рендерера
web/                     отладочный клиент
migrations/              SQL-схема
test/                    тесты правил, генератора и сервера (на реальной PostgreSQL)
```

## API (кратко)

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/telegram` | `{initData}` → токен сессии |
| GET/POST | `/api/matches` | мои партии / создать (`preset`: `quick`, `async`, `vsbot`, `campaign`; `faction`; `victory`, `turnLimit`, `alliances`) |
| POST | `/api/matches/:id/faction` | смена народа в лобби |
| POST | `/api/matches/:id/bots` | добавить ботов в лобби (создатель) |
| GET/POST/DELETE | `/api/matches/:id/markers` | метки на карте (общие видят союзники) |
| GET | `/api/rules` | справочник правил из конфигурации баланса |
| POST | `/api/matches/:id/start` | старт создателем (от 2 игроков) |
| POST | `/api/matches/join` | `{inviteCode}` |
| GET | `/api/matches/:id/state` | представление игрока, его приказы, резерв |
| GET | `/api/matches/:id/chunks?list=0,0;1,0` | местность с учётом тумана |
| GET | `/api/matches/:id/events?turn=N` | видимые игроку события хода |
| GET | `/api/matches/:id/minimap` | исследованная местность, города, видимые отряды |
| POST/DELETE | `/api/matches/:id/orders` | приказ `{turn, order, idempotencyKey, baseVersion?}` / отмена. Отряды: `move` (+`longRoute`, `stopOnThreat`), `attack` (+`ability: knockback`), `hold`, `build` (`road`, `fort`, `forest`); города: `recruit`, `construct`, `specialize`; `research`, `promote`, `commander` (`ability` / `direction`), `diplomacy` (`propose` / `accept` / `decline` / `break`) |
| POST | `/api/matches/:id/ready` | готовность |
| GET | `/api/matches?archived=1` | мои партии / личный архив (удалённые комнаты не показываются) |
| DELETE | `/api/matches/:id` | удалить комнату ожидания (только создатель, до старта; мягкое удаление) |
| POST | `/api/matches/:id/leave` | покинуть комнату ожидания (участник) |
| POST | `/api/matches/:id/surrender` | сдаться в идущей партии (повтор безопасен) |
| POST / DELETE | `/api/matches/:id/archive` | убрать завершённую партию из своего списка / вернуть |
| GET | `/api/matches/:id/summary` | итоги завершённой партии (владения, потери, изменение рейтинга) |
| GET | `/api/matches/:id/replay?turn=N` | повтор рассчитанного хода: вид игрока до и после, его события |
| GET | `/api/leaderboard` | рейтинг: топ-50 и своё место, текущий сезон, призёры прошлого |
| GET | `/api/referral` | ссылка «позвать друга» и счётчики приглашённых |
| POST | `/api/share` | `{kind: invite\|result\|referral, matchId?}` → текст, ссылка, `preparedId` для `Telegram.WebApp.shareMessage` |
| GET/POST | `/api/matches/:id/preview/moves`, `/preview/attack` | подсветка и прогноз боя |
| WS | `/ws?token=…` | `subscribe` → `turn_resolved`, `match`, `ready_changed` |
