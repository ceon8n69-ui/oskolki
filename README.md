# Осколки королевств

Telegram-бот проекта: https://t.me/oskolki_k_bot

## Текущий статус
Версия 0.1 — одиночный браузерный прототип. Карта 256×256, локальный противник, движение, атаки, найм, базовое исследование. Сохранение — localStorage браузера. Сервер ниже только раздаёт файлы: авторизация Telegram, серверная игровая логика и мультиплеер пока отсутствуют. Графика упрощённая, не финальная.

## Запуск
Node.js 22 или новее. Внешних зависимостей нет.

```sh
npm run check
npm start
```

Открыть http://localhost:3000. Переменная PORT задаёт порт. Проверка доступности: GET /health.

## Подключение Mini App
После размещения приложения на доступном игрокам HTTPS-домене настройте в BotFather кнопку меню бота @oskolki_k_bot на этот адрес. Приватная ссылка предпросмотра Sites не является готовым публичным адресом Telegram Mini App. Токен бота не нужен для раздачи прототипа. Для серверной проверки Telegram initData и уведомлений он потребуется в секретах серверного окружения; не добавляйте токен в репозиторий или клиентский код.
